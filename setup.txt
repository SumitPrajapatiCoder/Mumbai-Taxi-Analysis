MUMBAI TAXI TRIP DATA ANALYSIS
===============================

SETUP AND RUN INSTRUCTIONS

Project Stack:
- Python 3.10
- PySpark
- Pandas
- Django
- Chart.js
- Font Awesome CDN

Project Folder:
D:\Sumit\BDA Mini Project\Mumbai-Taxi-Analysis


1. OPEN PROJECT FOLDER
======================

Open PowerShell:

cd "D:\Sumit\BDA Mini Project\Mumbai-Taxi-Analysis"


2. CREATE VIRTUAL ENVIRONMENT
=============================

Only if venv does not already exist:

python -m venv venv


3. ACTIVATE VIRTUAL ENVIRONMENT
================================

PowerShell:

.\venv\Scripts\Activate.ps1

If PowerShell gives an execution-policy error, use Command Prompt:

venv\Scripts\activate.bat

After activation you should see:

(venv)


4. INSTALL REQUIRED PACKAGES
============================

If requirements.txt exists:

pip install -r requirements.txt

Otherwise:

pip install django
pip install pyspark
pip install pandas
pip install matplotlib
pip install seaborn
pip install joblib


5. CHECK PYTHON
===============

python --version

Expected:

Python 3.10.x


6. CHECK PYSPARK
================

python -c "import pyspark; print(pyspark.__version__)"

8. TEST PYSPARK
===============

python pyspark/test_spark.py

If Spark starts successfully, PySpark is working.

Windows may show warnings such as:
- winutils.exe not found
- HADOOP_HOME is not set
- Unable to load native-hadoop library

These warnings are expected for this local setup.
A full Hadoop/HDFS installation is not required for this project.


9. LOAD DATA
============

python pyspark/data_loading.py

Expected dataset size:

1,048,576 rows


10. DATA CLEANING
=================

python pyspark/data_cleaning.py

This checks/handles:
- Missing values
- Duplicate records
- Invalid passenger counts
- Invalid distances
- Invalid fares


11. RUN DATA ANALYSIS
=====================

python pyspark/analysis.py

This generates analysis results inside:

results/

Main analysis:
- Basic statistics
- Trips by hour
- Monthly trips
- Top pickup locations
- Top drop-off locations
- Payment methods
- Passenger analysis
- Distance/fare analysis
- Average fare by location


12. START DJANGO
================

python manage.py runserver


13. OPEN DASHBOARD
==================

Open:

http://127.0.0.1:8000/


14. DASHBOARD FEATURES
======================

KPI Cards:
- Total Trips
- Average Distance
- Average Fare
- Average Passengers

Charts:
- Trips by Hour
- Monthly Trip Trend
- Top Pickup Locations
- Top Drop-off Locations
- Payment Methods
- Passenger Analysis
- Average Fare by Location

Filters:
- Pickup Location
- Payment Method
- Passenger Count


15. USE FILTERS
===============

Select a filter and click:

Apply Filter

Example:

Pickup Location = Andheri
Payment Method = UPI
Passengers = 2

The KPIs and charts update according to the selected data.

To remove filters:

Click Reset.


16. STOP DJANGO SERVER
======================

Press:

CTRL + C


17. DEACTIVATE VENV
===================

deactivate
